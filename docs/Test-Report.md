# Лабораторная работа № 4

## Цель и план

Проверить четыре функции Python-библиотеки. Для круга это площадь πr² и длина окружности 2πr, для квадрата — площадь a² и периметр 4a. Проверены обычные, нулевые и дробные размеры, а также неверные аргументы.

Ожидаемые числа получены из формул. Целые и нулевые результаты сравнивались точно, дробные результаты для круга — с допуском. Для неверных аргументов проверялся тип исключения. Среда испытаний — Python 3.14.2, macOS.

## Итог

**Из 12 тестов прошло 10, не прошло 2.** В кейсе 03 отрицательный радиус возводится в квадрат. В кейсе 12 умножение строки на 4 повторяет её. Для этих двух кейсов исключения указаны как предлагаемые правила валидации. Текущая документация поведение на таких входах не определяет.

**Критерий приёмки.** Все проверки расчётов должны пройти. Проверки 03 и 12 показывают, какое поведение нужно согласовать для недопустимых входов.
